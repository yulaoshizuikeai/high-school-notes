> 系统整理的高中学科笔记，涵盖数学、物理、生物、英语、语文五大学科。

## 📖 项目简介

本项目是一套完整的高中学科知识笔记，适合高中生复习备考使用。笔记采用 Markdown 格式编写，支持在 Obsidian、Typora 等 Markdown 编辑器中阅读。

## 📁 目录结构

```
├── 高中数学/          # 数学笔记
├── 高中物理/          # 物理笔记
├── 高中生物/          # 生物笔记
├── 高中英语/          # 英语笔记
└── 高中语文/          # 语文笔记
```
