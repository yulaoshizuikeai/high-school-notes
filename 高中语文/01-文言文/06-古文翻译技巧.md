# 古文翻译技巧

## 文言文翻译题答题技巧

**流程：**

1. 逐字翻译（比如"请求"，也要逐字翻译）
2. 连接通顺
3. 结合原文，使之完整：加主语等





信：基本词义语义，信息传达无误：

* 留

  泽有……：湖里有……
* 删：无实义或没必要译的虚词、衬词删去，注意互文的修辞手法

  **夫**赵强而燕弱

  备他盗之**出**入与非常也：为了防备其它盗贼的进入和意外变故

  **因利乘便**：凭借有利的形势
* 换：古今异义词、通假字、单音词、词类活用等

  臣本**布衣**，**躬耕**于南阳

  愿伯具言臣之不敢**倍**德也：背叛

  此愚者之所以大过也：这就是愚笨的人会犯大错误的原因

达：通顺，语序恰当，逻辑清楚

* 补调：特殊句式（省略句、倒装句）

  不如因而厚遇之，使（+之）归赵

  君何以（以何）知燕王

  石之铿然有声者（铿然有声者石）

  故燕王欲结于君（于君结）
* 贯：融会贯通

  有席卷天下，包举宇内，囊括四海之意，并吞八荒之心：有统一天下的心愿

  金城千里：坚固的城池绵延千里

雅：文化内涵，语言美感

## 💡 翻译原则

### 十六字方针
> **字字落实，句句对应，直译为主，意译为辅**

### 翻译方法
| 方法 | 说明 |
|------|------|
| 留 | 保留人名、地名、官职 |
| 换 | 古今词语转换 |
| 补 | 补充省略成分 |
| 删 | 删除虚词 |
| 调 | 调整语序 |
