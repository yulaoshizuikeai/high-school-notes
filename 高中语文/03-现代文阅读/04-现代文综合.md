# 现代文阅读

## 论述类文本阅读

答题思路：

* 速读原文
  1. 划关键词：时间，范围，概率，状态，逻辑关系
  2. 划关键句：中心句，总起句，总结句，过渡句，段首句，富有特色句
  3. 理清句子逻辑：原因，结果，条件，作用，目的
* 找
* 比（分辨，判断，推翻）
  * 排查分句关系：因果、条件、假设、目的
  * 寻找原文依据：是否强加、倒置、无中生有

出题人挖坑位置：概念、判断、推理

出题人挖坑方法：添加信息，删除信息，改换信息

题型：

* 无中生有
* 主次颠倒
* 以偏概全
* 偷梁换柱
* 因果颠倒

注意：

* 定性词：主要表现、多为、几乎等词**≠**全部





> 分辨：
>
> 1、语法类错误(原文基本对应，只改变了成分，句意未变)(抠字眼)
> 2、逻辑类错误(句与句之间的关系改变，强行加入错误逻辑)
> 3、手法类错误(手法、体裁、常识等)(没有就是错的)
> 4、转述类错误(文差意同)(原文改动很大，句意发生改变)(推翻不了就是对的)
> 5、概述、结论类错误(原文无对应内容，是出题老师得出的推论)(概述先跳过，结论三种情况)

> 语法类：
>
> * 以偏概全
> * 偷换概念
> * 可能与必然
> * 是非颠倒
> * 未然与已然
> * 张冠李戴
>
> 逻辑类错误：
>
> * 强加因果
> * 多对一
> * 前后颠倒
> * 强加逻辑
>
> 手法类错误：……论证
>
> * 距离
> * 引用：使用了别人的内容
> * 对比
> * 比喻
> * 类比
> * 因果
> * 归纳
> * 演绎
> * 归谬
>
> 转述类错误：推翻不了即正确
>
> 结论类错误



## 现代文阅读整体感知

形成整体印象，然后揣摩文章的谋篇布局、遣词造句，最后再回到文章，获得文章的整体印象

整体——局部——整体

### 读懂阅读材料：草稿纸演算法，记录关键信息

小数：线索→性格

散文：象征物→感情

传记：大事年表（时—事）

## 题型

归纳概括题

含义题

文章结构题

艺术手法题

延伸探究题

## 答题技巧/原则

* 标明序号
* 分散重点，多分多答
* 踩分点在前，原因在后，组织好逻辑

## 含义题：重要词语/重要句子/文章标题

语境义：

* 修辞义：比喻，象征，**双关**，反语
* 主旨义
* 背景义——注释

答题原则/内容：

* 本义
* 语境义
* 表达效果
* 对中心/主旨/结构作用

### 重要句子

重要句子：

* 表达作者观点态度或写作意图的句子（从内容上看）
* 总领句、总结句和重要的过渡句（从结构层次上看）
* 含义深刻丰富而形式富有特色的句子（从表达效果上看）
* 反复出现的句子（从出现的频率上看）

答题原则：

* 以关键词语为中心——修辞义（比喻，比拟，借代，反语）
* 修辞分析法
* 句子定位法
* 联系主旨分析表达效果

### 语段作用

题型

* 某段是否可以删去
* 围绕展开的故事，谋篇与立意
* 出现了三次，有何用意

答题原则：

* 探究文章内容、作者情感，中心思想上的作用
* 探究文章结构上的作用
* 总分总、先抑后扬、逐层递进、前后照应；文眼、以小见大、线索、情节、形散神聚、点面结合、悬念、意外、巧合
* 探究表达效果上的作用

## 艺术手法

**艺术手法=表达技巧=表达方式+表现手法+修辞手法**

表达技巧=表现手法（广义）

表达方式：

* 说明（较少出现）
* 记叙：顺叙，倒叙，插叙（结构）
* 描写：
  * 正面/侧面（侧面：周围人物或环境的描绘来表现所要描写的对象，以使其鲜明突出，即间接地对描写对象进行刻画描绘）
  * 细节描写/白描
* 抒情：直抒胸臆/间接抒情
* 议论

表现手法：

* 象征
* 对比/衬托：看主次；是目的还是手段（衬托可作为目的）
* 联想/想象

修辞手法：

* 比喻/比拟：相似性
* 借代/夸张：相关
* 排比/对偶/反复
* 设问/反问

答题：点关键手法——分析内容——评价作用
