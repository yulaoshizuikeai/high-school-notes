## 💡 核心记忆口诀

- **受力分析**：重弹摩，外力多
- **动量守恒**：系统内力或外力之和为零
- **机械能守恒**：只有重力和弹簧弹力做功
- **左力右感**：左手定则判力，右手定则判感应电流
- **楞次定律**：增反减同
