# 比较级最高级

单音节词/少数多音节词：

* 基本变化：-er, -est
* e结尾：加-r -st
* 辅音字母+y结尾：去y加-ier, -iest
* 双写辅音字母，再加-er, -est

多数多音节词：词前加more, most



| 特例      |                 |                   |
| --------- | --------------- | ----------------- |
| good/well | better          | best              |
| many/much | more            | most              |
| far       | farther/further | farthest/furthest |
| bad/ill   | worse           | worst             |
| little    | less            | least             |
| old       | older/elder     | oldest/eldest     |
