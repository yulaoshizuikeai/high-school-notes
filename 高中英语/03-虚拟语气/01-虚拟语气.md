# 虚拟语气

## 虚拟语气

|           | 主句            | 从句     |
| --------- | --------------- | -------- |
| 过去      | would have done | had done |
| 现在/将来 | would do        | did      |

标志：if/would have done/otherwise/or/without/but for...



**需特殊处理的：wish/as if/as though+**

* 过去：had done
* 现在：did
* 将来：would do



区分：

* would：主句一定有，从句没有
* have：过去一定有，现在将来一定没有
* be动词没有was只有were
* 根据空格当前句子时间判断
* 绝对没有will



虚拟语气倒装：

* Had I= If I had
* Were I= If I were
* Should I=If I should



the minute/when/as soon as/the moment 当……时



> 祈使句：表将来（还没做过），也是主将从现
>
> Try not to wake up the baby if you go into the room.

> The painting _ to someone who later donated it to the college.  **考点：过去，被动**
>
> A. had sold  **B. was sold** C. will sell D. is sold **E. had been sold**

> You know, I _ for a job for three months, but I haven't get any luck.  **过去现在，强调动作延续**
>

## 💡 快速判断技巧

### 虚拟语气判断口诀
> **if条件虚拟看，主从时态要留意**
> **主句would是标配，从句时态往后退**

### 记忆技巧：**退一格原则**
- 表示**与现在/将来相反**：从句用**过去时**（退一格），主句用 would do
- 表示**与过去相反**：从句用**过去完成**（再退一格），主句用 would have done

### 虚拟语气速记表
| 与...相反 | 从句 | 主句 |
|-----------|------|------|
| 现在/将来 | **did/were** | would do |
| 过去 | **had done** | would have done |

### 五大标志词一定要记
1. **if** - 最常见
2. **wish** - 希望（但实际不是）
3. **as if/as though** - 好像（但实际不是）
4. **without/but for** - 要不是
5. **otherwise/or** - 否则

### 倒装形式速记
把if省略，助动词提前：
- Had I = If I had
- Were I = If I were
- Should I = If I should

### 解题妙招
1. 看到 **would have done** → 99%是虚拟语气
2. 虚拟语气中 **永远没有 will**
3. be动词虚拟中 **只用were，不用was**
