# 作文句式升级

## 💡 四大升级原则

### 1. 陈述不如倒装好
**普通**：Our school lies by the side of a river.
**高级**：By the side of river **lies** our school.

**普通**：He ran to help the little boy as soon as he heard...
**高级**：Hardly **had** he run to help the little boy **when** he heard...

### 2. 状从不如分词好
**普通**：Because I am a student, I should study hard...
**高级**：**Being** a student, I should study hard...

### 3. 肯定不如否定好
**普通**：Everyone is affecting others more or less.
**高级**：There is **hardly** a man or a woman who is **not** affecting...

### 4. 主动不如被动好
**普通**：Nowadays, we can also use cell-phones as cameras.
**高级**：Nowadays, cell-phones can also **be used** as cameras.

## 高频词替换表

| 低级表达 | 高级替换 |
|----------|----------|
| I think | In my opinion / As far as I'm concerned |
| more and more | a growing number of / increasingly |
| very important | vital / significant / essential |
| very good | remarkable / outstanding / splendid |
| very happy | delighted / cheerful / thrilled |
| very difficult | challenging / tough |
| want | be eager to / long for |
| because | owing to / due to / thanks to |
| if | provided that / assuming that / given that |
| as soon as | instantly / on doing / hardly...when |
