# 八种基本时态

* 双写辅音字母，再加-er, -est

多数多音节词：词前加more, most



| 特例      |                 |                   |
| --------- | --------------- | ----------------- |
| good/well | better          | best              |
| many/much | more            | most              |
| far       | farther/further | farthest/furthest |
| bad/ill   | worse           | worst             |
| little    | less            | least             |
| old       | older/elder     | oldest/eldest     |

## 💡 快速判断技巧

### 时态选择口诀
> **看时间，定时态；看主被，定语态**

### 时态判断三步法
1. **找时间标志词**：yesterday, now, tomorrow, since, by the time...
2. **看动作状态**：是一般、进行还是完成？
3. **判断主被动**：主语是动作执行者还是承受者？

### 比喻理解
- **一般时态** = 拍照📷 (定格某一状态)
- **进行时态** = 录像🎬 (强调正在发生)
- **完成时态** = 回顾总结📊 (强调对现在的影响)

### 常见时间标志词
| 时态 | 标志词 |
|------|--------|
| 一般过去 | yesterday, last..., ago, in 2020 |
| 一般现在 | always, usually, every day |
| 一般将来 | tomorrow, next..., soon |
| 现在完成 | already, yet, since, for, ever |
| 过去完成 | by the time, had...before |
