# 完形填空答题技巧

## 核心理念
> **100%拿下第一句：找主线，拆首句**
> **关键：不要瞎蒙，证据不足就是蒙**

---

## 💡 做题要点

### 四字口诀
| 口诀 | 含义 |
|------|------|
| 瞻前顾后 | 通览全文，重视首尾句 |
| 左顾右盼 | 注意上下文逻辑 |
| 顾全大局 | 全面检查 |
| 义无反顾 | 不大面积修改 |

### 选项秘密
| 词类 | 技巧 |
|------|------|
| 动词 | 根据前后搭配 |
| 名词 | 找同类词 |
| adj/adv | 看感情色彩（正/负/中） |
| 介词连词 | 根据逻辑关系 |

---

## 常见逻辑词

| 逻辑 | 词汇 |
|------|------|
| 因果 | because, since, due to, therefore |
| 转折 | but, however, although, while |
| 并列 | and, also, as well as |
| 递进 | moreover, furthermore, besides |
