# 语法填空答题技巧

## 一般原则
- ✗ 不抄原词
- ✗ 不由繁到简（如 truthful→truth）
- ✓ 按要求填写

---

## 💡 分类攻略

### 有提示词

| 词类 | 考点 |
|------|------|
| 动词 | 时态语态、非谓语、词形变换 |
| 名词代词 | 单复数、人称变化、反身代词 |
| 形容词副词 | 词形变换、比较级最高级 |

### 无提示词（只填1个词）

| 空格后 | 填什么 |
|--------|--------|
| 句子 | 关系词/连词 |
| 动词短语 | 冠词/介词/and/or/but |
| 名词短语 | 从句关系词/连词 |

---

## 关系词速查

| 主句 | 从句 | 用词 |
|------|------|------|
| 不完整 | 不完整 | what(物) / who(人) |
| 不完整 | 完整 | when, where, how, whether, **that** |
| 完整 | 不完整 | that/which(物) / who(人) / whose |
| 完整 | 完整 | when(时间) / where(非时间) |

### 特殊情况
- 逗号后 → 不用that，用who/which
- 介词后 → 不用that，用whom/which
- 不定代词后 → 只用that
- 最高级/极端词后 → 只用that
