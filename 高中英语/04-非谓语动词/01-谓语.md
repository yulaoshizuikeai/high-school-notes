# 谓语

be: am/is/are

|           | 主动                          | 被动                         |
| --------- | ----------------------------- | ---------------------------- |
| 过去      | did, was/were doing, had done | was/were done, had been done |
| 过去+现在 | have/has done                 | have/has been done           |
| 现在      | do/does, be doing             | be done                      |
| 将来      | will do                       | will be done                 |

很少考的：

* have/has been doing
* will be doing
* would do/would be done
* be being done
* was/were being done
* will be being done

## 情态动词

12个（有not是否定）：

* can/could (not) do
* will/would (not) do
* may/might (not) do
* must (not) do
* should (not) do
* (do not) have to 
* be (not) able to do
* be (not) supposed to do
* ought to do（否定忽略）



| 情态动词                       | 按作用分类               |
| ------------------------------ | ------------------------ |
| can, could, be able to         | 能力                     |
| should, will must ought to     | 观点，建议，结论         |
| may, might, can, could, should | 推测，不确定或委婉的语气 |
| must, have to, ought to        | 强调必要性或要求         |
| will                           | 表示意愿或计划           |



## 被动语态

注意：

* 动词有宾语才能变成被动语态
* be动词或助动词要和主语保持一致



| 主动            | 被动（有not的是否定）    |
| --------------- | ------------------------ |
| do/does         | am/is/are (not) done     |
| did             | was/were (not) done      |
| will do         | will (not) be done       |
| have/has done   | have/has (not) been done |
| had done        | had (not) been done      |
| am/is/are doing | am/is/are being done     |
| was/were doing  | was/were being done      |
| 情态动词+do     | 情态动词+(not) be done   |

had done：过去2个动作排序
