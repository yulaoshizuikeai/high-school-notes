# 导数

函数在某一个点的导数就是函数在这个点的瞬时变化率，也是这个点函数图像切线的斜率

导数是数，导函数不是数



f(x)在$x=x_0$处的导数$f'(x_0)$的集合意义是曲线y=f(x)上点$(x_0,f(x_0))$处的切线的斜率，切线方程为$y-f(x_0)=f'(x_0)(x-x_0)$



## 函数的导数

| 函数          | 导数                   | 说明                                    |
| ------------- | ---------------------- | --------------------------------------- |
| f(x)=c        | f'(x)=0                |                                         |
| f(x)=x        | f‘(x)=1                |                                         |
| $f(x)=x^n$    | $f'(x)=nx^{n-1}$       | （n∈Q*，非0有理数）指数换系数，指数减一 |
| f(x)=sinx     | f'(x)=cosx             |                                         |
| f(x)=cosx     | f'(x)=-sinx            |                                         |
| $f(x)=a^x$    | $f'(x)=a^xlna$         |                                         |
| $f(x)=e^x$    | $f'(x)=e^x$            | 导数等于函数                            |
| $f(x)=log_ax$ | $f'(x)=\frac{1}{xlna}$ |                                         |
| f(x)=lnx      | $f'(x)=\frac 1 x$      |                                         |



偶函数的导函数是奇函数，奇函数的导函数是偶函数。反过来不一定成立：

* 导函数是奇函数，原函数是偶函数
* 导函数是偶函数，原函数不一定是奇函数：常数求导为0，如果能证明常数为0，可成立

## 导数分析函数的单调性、极值、最值

如果函数y=f(x)在某个开区间内，总有f'(x)>0，则f(x)在这个区间上是增函数；总有f'(x)<0，则在这个区间是减函数

开区间(a,b)：f'(x)>0：f(x)递增

开区间(a,b)：f'(x)<0：f(x)递减





研究函数单调性方法：

1. 求f(x)定义域
2. 求f'(x)。令f'(x)=0，分解因式，求零点；无法分解的**可猜根**，特殊值-1,0,1,e等试根
3. 列x，f'(x)，f(x)变化情况表，写出单调区间
4. 综合写出完整单调区间，多个相同单调区间用逗号隔开，不能用并集∪连接



求f(x)中的参数值问题，往往转化为不等式的恒成立问题，即f'(x)≥0在D上恒成立



> 求导，因式分解之后，函数图像不好画，求出零点，转化为一元二次方程的根的式子（注意开口方向），然后判断单调性。比如：
>
> > $(e^x-1)(1-2e^x)$，算出两根，转化为$(ln\frac 1 2-x)x$，开口向下，然后判断单调性

## 函数的极值与倒数

极值点：极大值点和极小值点

极值：极大值和极小值，**极大值不一定比极小值大**



注意：

* 极值是函数局部性质，有极值：不是单调函数
* 极值点是函数区间内部的点，不会是端点
* 极值点导函数值=0，导函数值=0的点不一定是极值点。如$f(x)=x^3，f'(x)=0$，但x=0不是极值点



求函数y=f(x)极值的方法：解方程f'(x)=0，当$f'(x_0)=0$时：

* 如果在$x_0$附近左侧f'(x)>0，右侧f'(x)<0，那么$f(x_0)$是最大值
* 如果在$x_0$附近左侧f'(x)<0，右侧f'(x)>0，那么$f(x_0)$是最小值



求函数y=f(x)在[a,b]上的最大（小）值的步骤：

* 求函数y=f(x)在(a,b)内的极值
* 1个极值时，直接得到最值
* 多个极值时，算出极值比较/作差比较得到最值



注意：

* 某区间端点处的函数值可能是最值，但不一定是极值
* 图像连续不断的函数不一定有最大（小）值，如果图像连续不断的函数在开区间(a,b)只有一个极值，那么该极值就是最值

## 导数优化问题

连续函数：y=f(x)在某个区间I上的图像是连续不断的曲线，那么把它称为区间I上的连续函数

曲边梯形：由直线x=a, x=b(a≠b)， y=0和曲线y=f(x)所围成的图形



### 定积分

$\xi$：读塞，克赛，希腊：xi

定积分：如果函数f(x)在区间[a,b]上连续，用分点$a=x_0<...<x_n=b$将区间[a,b]分为n个小区间，每个小区间$[x_{i-1}, x_i]$上任取一点$\xi_i(i=1,2,...,n)$，作和式$\sum\limits_{i=1}^{n}f(\xi_i)△x=\sum\limits_{i=1}^{n}\frac{b-a}{n}f(\xi_i)$ ，当n→∞时，上述和式无限接近某个常数，这个常数叫做函数f(x)在区间[a,b]上的定积分，记作$∫_a^b f(x)dx$，即：

$∫_a^b f(x)dx=\lim\limits_{n→∞}\sum\limits_{i=1}^{n}\frac{b-a}{n}f(\xi_i)$，这里a与b分别叫做积分下限与积分上限，区间[a,b]叫做积分区间，函数f(x)叫做被积函数，x叫做积分变量，f(x)dx叫做积式



用定义求定积分的一般步骤：

* 分割：n等分区间[a,b]
* 近似代替：取点$\xi∈[x_{i-1},x_i]$
* 求和：$\sum\limits_{i=1}^{n}f(\xi_i)·\frac{b-a}{n}$
* 取极限：$∫_a^b f(x)dx=\lim\limits_{n→∞}\sum\limits_{i=1}^{n}f(\xi_i)\frac{b-a}{n}$



定积分$∫_a^b kf(x)dx$不是一个函数式，而是一个**常数**

> $∫_{-b}^b kf(x)dx$的几何意义是介于x轴、函数f(x)的图像以及直线x=-b，x=b之间各部分面积的代数和，在x轴上方的面积取正号，x轴下方的面积取负号



定积分性质：

* $∫_a^b kf(x)dx=k∫_a^bf(x)dx$，k为常数
* $∫_a^b [f_1(x)±f_2(x)]dx=∫_a^b f_1(x)dx±∫_a^b f_2(x)dx$
* $∫_a^b f(x)dx=∫_a^c f(x)dx+∫_c^b f(x)dx$，其中a<c<b



定积分的几何意义：如果在区间[a,b]上函数f(x)连续且恒有f(x)≥0，那么定积分$∫_a^b f(x)dx$表示由直线x=a, x=b, y=0和曲线y=f(x)围成的曲边梯形面积



## 微积分基本定理

如果f(x)是区间[a,b]的连续函数，并且F'(x)=f(x)，则$∫_a^b f(x)dx=F(x)|_a^b=F(b)=F(a)$。这个结论叫做微积分基本定理/牛顿—莱布尼茨公式



常用定积分公式：

* $(cx)'=c→∫_a^b cdx=cx|_a^b$
* $(x^n)'=nx^{n-1}→∫_a^b x^ndx=\frac{1}{n+1}x^{n+1}|_a^b$
* $(sinx)'=cosx→∫_a^b cosxdx=sinx |_a^b$
* $(cosx)'=-sinx→∫_a^b sinxdx=-cosx|_a^b$
* $(lnx)=\frac 1 x→∫_a^b \frac 1 xdx=ln|x||_a^b$
* $(e^x)'=e^x→∫_a^b e^xdx=e^x|_a^b$
* $(a^x)'=a^xlna→∫_a^b a^xdx=\frac{a^x}{lna}|_a^b$



定积分几何意义：

* 对应的曲边梯形位于x轴上方时，定积分值为正，且等于曲边梯形面积；下方时，定积分值为负，且等于曲边梯形面积的相反数
* 当位于x轴上方曲边梯形的面积等于位于x轴下方曲边梯形的面积时，定积分的值为0，且等于位于x轴上方减去下方的曲边梯形的面积



## 定积分的简单应用

几何中：求平面图形的面积的步骤：

* 画图形：画出图形，确定图形范围
* 求交点：通过解方程组求出交点的横坐标，确定积分的上下限，特别要注意分清被积函数的上下位置
* 列式：写出平面图形面积的定积分表达式
* 计算面积：运用微积分基本定理计算定积分，求出平面图形的面积



做变速直线运动的物体经过的路程s，等于其速度函数v=v(t)(v(t)≥0)在区间[a,b]上的定积分，即$s=∫_a^bv(t)dt$

求变力做功：一物体在恒力F作用下，沿着与F相同的方向移动了s，则力F做功W=Fs，如果力是变力F(x)，由定积分的定义，物体沿与F(x)相同的方向从x=a移动到x=b(a<b)时，变力F(x)所做的功是$W=∫_a^bF(x)dx$

### 单变量不等式恒成立问题

f(x)<g(x)，任意x∈[a,b]，恒成立：

* 当区间端点带入f(x)≠g(x)，或者无穷大无法计算时，使用分离参数法
* 当x=a，f(a)=g(a)时，不分离a更好做。转为h(x)=f(x)-g(x)<0，证明h(x)最大值<0。缩参，用g'(x)≤0，算出a至少满足的条件，然后如果a能反推出g'(x)≤0，则证明成立



分离参数法：

* 分离参数a，转化为h(x)<a；形如x^a无法分离的，取对数
* 令h(x)=f(x)-g(x)<0，h(x)最大值<0



### 函数恒单调，求参数问题

f(x)在区间上恒增→f'(x)≥0在区间恒成立。然后求导，因式分解，对于不确定符号的g(x)部分确定符号，使条件成立，对g(x)分离参数，利用函数性质算出参数范围



### 单变量不等式存在性问题

转化为使最值满足条件。f(x0)<g(x0)可分离参数，或者转化为f(x0)-g(x0)<0均可

> 当分离参数乘除，但不确定正负，是否变号时，不采用分离参数法，而是转化为g(x)<0



### 双变量恒成立/存在性问题

* 任意x1，总存在x2，使得f(x1)≤f(x2)↔f(x)最大值≤g(x)最大值

* 存在x1，总存在x2，使得f(x1)≤f(x2)↔f(x)最小值≤g(x)最小值
* 任意的x1，x2，使得f(x1)≤f(x2)↔f(x)最大值≤g(x)最小值
* 存在x1，总存在x2，使得f(x1)≤f(x2)↔f(x)最小值≤g(x)最大值



方法：

* 整体法
* 半边分析，算出不带参数的函数**区间**最值，转为单变量问题

> 求谁的范围，谁就是常量。a是变量时，要分离a和x；如果分离不了（比如ln(ax)），则把任意变量当做常量，研究存在变量



任意x1，存在x2，f(x1)=g(x2)↔g(x)值域包含f(x)值域



任意x0，y=f(x)-g(x0)在区间有2个不同的零点，求a范围↔f(x)=g(x0)在区间有2个根→任意x0，存在x1,x2，f(x1)=g(x0)，g(x2)=g(x0)：

1. 先求g(x)在区间的值域
2. k属于值域，使f(x)=k有2个不同交点
3. f(x)求导，注意：当f(x)整体单调时，和k最多1个交点，不符



存在x1,x2，f(x1)=g(x2)↔值域有交集/交集为空的范围取反



### 多元函数/2个变量不等式的证明

方法：

* 整体换元，化为一元不等式，求导利用单调性证明
* 如果函数不等式具有对称性，并且可以将2个变量分离，分离之后的函数结构相似，从而构造函数求导利用单调性证明



### 极值点偏移问题

两个零点运算之后符合某个条件的证明：

1. 求x1,x2范围
2. 分离x1,x2，构造函数证明
3. 当有变量a时，利用零点f(x1)=0，表示出a=?，消去a



### 隐零点问题

算/猜不出导函数的根时：

1. 设x0，说明x0的：存在性，范围/极值，等式关系（如果x0带入原函数得到x0=?，最后按需代换）
2. 得到g(x0)=?，x0范围，根据条件得到变量的范围



f(x)在x=x0时切线斜率与k无关：k相关的整理到一起，令k相关的括号内等于0

### 常用导数公式

|------|------|
| xⁿ | nxⁿ⁻¹ |
| sinx | cosx |
| cosx | -sinx |

### 求导法则
- 和差：(u±v)' = u' ± v'
- 积：(uv)' = u'v + uv'
- 商：(u/v)' = (u'v - uv')/v²
- 复合：[f(g(x))]' = f'(g(x))·g'(x)

### 导数应用
1. **单调性**：f'(x)>0增，f'(x)<0减
2. **极值**：f'(x)=0的点
3. **最值**：比较极值点和端点

### 解题口诀
> **求导找零点，列表判单调**
